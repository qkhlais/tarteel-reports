# منصة التقارير الشهرية - جمعية ترتيل

صفحة واحدة مستقلة (index.html) لا تحتاج خادماً. تُرفع على GitHub Pages.

- كل محور له رابط مستقل، مثل: `#res-3` (المبادرات) و `#media-4` (المنصات) و `#res-view` (عرض التقرير).
- التقارير تُحفظ في متصفح الجهاز (localStorage).
- من الصفحة الرئيسية: «حفظ نسخة احتياطية» و«استيراد نسخة أو تقرير» (ملف JSON).
- من «عرض التقرير كاملاً»: تحميل PDF بمقاس A4 أو طباعة مباشرة.
